# Plate illustrations

Line drawings used on the landing page's route map (`app/routes/home.tsx`).

All four are from the **Pearson Scott Foresman** archive — a collection of
textbook illustrations released into the **public domain** and donated to
Wikimedia Commons. No attribution is required; it is given here anyway.

| File | Source |
|---|---|
| `ship.png` | [Ship-Of-The-Line (PSF)](https://commons.wikimedia.org/wiki/File:Ship-Of-The-Line_(PSF).png) |
| `archive.png` | [Doric Temple (PSF)](https://commons.wikimedia.org/wiki/File:Doric_Temple_(PSF).png) |
| `peak.png` | [Peak (PSF)](https://commons.wikimedia.org/wiki/File:Peak_(PSF).png) |
| `rose.png` | [Compass Card (PSF)](https://commons.wikimedia.org/wiki/File:Compass_Card_(PSF).png) |

Each is the 400px-wide rendering of the Commons original.

They are black line art on white, drawn into the map with
`mix-blend-mode: multiply` so the paper shows through, and inverted to
`screen` in the dark theme.
